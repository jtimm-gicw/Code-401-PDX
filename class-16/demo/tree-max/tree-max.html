🌳 Find the Maximum
in a Binary Tree

A visual, beginner-friendly walkthrough of how to visit every node, compare values, and return the largest number.

Concept first

🌱 What is a Binary Tree?

A node is a small container holding a value and links to up to two children. The first node is the root. A traversal means visiting the nodes one at a time.

Our mission

Look at every number in the tree. Remember the largest value found so far. Update it whenever a bigger number appears.

For the example below, the answer is 30.

⚠️ Binary Tree ≠ Binary Search Tree

A regular Binary Tree is not necessarily sorted. A bigger number might be on the left! We cannot simply follow the right-hand branch.

Build the solution

🛠️ From Nodes to an Answer

1. Build nodes and connect them

const tree = new BinaryTree();
tree.root = new Node(10);
tree.root.left = new Node(5);
tree.root.right = new Node(20);

left and right are links to other Node objects, not array indexes.

2. Call the required method

const answer = tree.findMaximumValue();
console.log(answer); // 20

The method takes no arguments and returns the largest numeric value in the tree.

3. Understand recursion

const traverse = (node) => {
  if (node === null) return;
  if (node.value > max) max = node.value;
  traverse(node.left);
  traverse(node.right);
};

At each node: check it, go left, then go right. When there is no node (null), stop that branch. Once all branches are checked, return max.

Negative-number tip: Start max with this.root.value, not 0. For -10, -30 and -5, the correct maximum is -5.

Whiteboard takeaway

📈 Time and Space Complexity

⏱️ Time: O(n)

We visit each node exactly once. 7 nodes = 7 visits. 100 nodes = 100 visits.

🧠 Extra space: O(h)

Recursion keeps track of the path down the tree. Here, h is the height of the tree.

  • Balanced tree: O(log n) memory.
  • Skewed tree: O(n) memory in the worst case.

The tree itself is existing input data; this space estimate counts the extra recursion stack.
