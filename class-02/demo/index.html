🔀 Insert Shift Array

Learn how to insert a new value into the middle of an array without using built-in array methods.

🎯 The Goal

Write a function called insertShiftArray. The function receives an array and a new value.

Your job is to create a new array with the new value inserted into the middle.

We are practicing the algorithm, so don't use splice(), push(), unshift(), or similar built-in methods.

🧠 Think of an Array Like a Row of Boxes

Start with this array:

2
4
6
-8

We want to insert 5 into the middle.

2
4
5
6
-8

The important idea is: we are creating a new array instead of changing the original array.

📍 Step 1: Find the Middle

JavaScript arrays start counting at index 0.

0
2
1
4
2
6
3
-8

We can calculate the middle with: 

const middleIndex = Math.floor(array.length / 2);

For an array with 4 items: 

Math.floor(4 / 2)
2

So index 2 is our insertion point.

🚶 Step-by-Step Algorithm

1
Create an empty result array.

This is where we will build our answer.

2
Find the middle index.

Use Math.floor(array.length / 2).

3
Loop through the original array.

Look at each value one at a time.

4
When you reach the middle, add the new value first.

Then add the original value that was already there.

5
Copy all other values.

Values before and after the middle are copied normally.

6
Return the result.

Our new array now contains the inserted value.

🧪 Example 1

Input

[2, 4, 6, -8]

New value: 5

Output

[2, 4, 5, 6, -8]

🧪 Example 2

Input

[42, 8, 15, 23, 42]

New value: 16

Output

[42, 8, 15, 16, 23, 42]

⏱️ Big-O

O(n) Time Complexity

We loop through the array once.

O(n) Space Complexity

We create a new array to hold the result.
