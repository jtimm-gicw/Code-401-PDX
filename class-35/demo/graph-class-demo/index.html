Graphs in JavaScript

A graph shows how things connect. A vertex is a thing (like a city). An edge is a connection (like a road). A weight is a number describing that connection (like distance).

Try the Interactive Graph ↓ Start Practice Exercises
1 • Understand

A graph is a list of connections

Imagine a map of cities and roads. In our challenge, we will store those connections using an adjacency list — a list of the neighbors for each vertex.

📍

Vertex (node)

One item in the graph, such as a city. A, B, and C are vertices.

🔗

Edge

A line connecting two vertices. For this lesson, edges work in both directions.

⚖️

Weight

A number attached to an edge, such as miles or travel cost. We use 1 when no weight is given.

        3 • Connect the ideas
        
What does this look like in JavaScript?

        
These examples show how the picture, the stored data, and the five challenge methods fit together.

      

      

        

          
Example A: Adjacency list

          
A → B (5), C (2)
B → A (5)
C → A (2)

          
A has two neighbors. B and C each have one neighbor. Each connection appears on both sides because our graph is undirected.

        

        

          
Example B: Create connections

          
const graph = new Graph();
const A = graph.addVertex('A');
const B = graph.addVertex('B');
const C = graph.addVertex('C');

graph.addEdge(A, B, 5);
graph.addEdge(A, C, 2);

          
First create the vertices. Then connect them using addEdge().

        

        

          
Example C: Ask the graph questions

          
graph.size();
// 3

graph.getVertices();
// [A, B, C] (vertex objects)

graph.getNeighbors(A);
// [{ vertex: B, weight: 5 },
//  { vertex: C, weight: 2 }]

          
Each method has one job: count, list, or inspect.

        

        

          
Example D: Handle an error

          
const missing = new Vertex('X');

graph.addEdge(A, missing);
// Error: Both vertices must
// already be in the graph.

          
Helpful errors tell the student exactly what went wrong instead of silently changing the graph.
