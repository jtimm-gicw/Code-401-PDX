# 🎯 Feature Tasks

Write a function called:

```text
validate brackets
```

### Arguments

```text
string
```

### Return

```text
boolean
```

The returned boolean should represent whether or not the brackets in the string are **balanced**.

# 🧩 Types of Brackets

There are **3 types of brackets**:

| Bracket Type | Brackets |
|---|---|
| Round Brackets | `()` |
| Square Brackets | `[]` |
| Curly Brackets | `{}` |

# 🧠 Challenge Goal at a Glance

Your function should determine whether brackets in a string are balanced.

```text
Round:   ( )
Square:  [ ]
Curly:   { }
```

The main question your algorithm needs to answer is:

> **Does every opening bracket have the correct closing bracket in the correct order?**
