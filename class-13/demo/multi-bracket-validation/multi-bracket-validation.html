Multi-Bracket Validation

How to check whether brackets are balanced

🎯 Goal

Create a function called:

validateBrackets(string)

Return true when brackets are balanced and false when they are missing, mismatched, or closed in the wrong order.

3. Why Use a Stack?

A Stack follows:

LIFO = Last In, First Out

The last bracket we open should be the first bracket we close.

Input: {[()]} Read { Stack: { Read [ Stack: [ { Read ( Stack: ( [ { Read ) ( matches ) POP ( Read ] [ matches ] POP [ Read } { matches } POP { Stack: EMPTY Answer: true

Opening bracket?

PUSH onto Stack

Closing bracket?
    ↓
Check TOP of Stack

Matches?
  ↙      ↘
NO       YES
↓         ↓
false     POP

5. Matching Brackets

const matchingBrackets = {
  ')': '(',
  ']': '[',
  '}': '{'
};

If we see ], the top of the Stack should be [.

6. Simple Algorithm

  1. Create an empty Stack.
  2. Loop through every character.
  3. If it is an opening bracket, push it.
  4. If it is a closing bracket, check the Stack.
  5. If the Stack is empty, return false.
  6. If the top does not match, return false.
  7. If it matches, pop the opening bracket.
  8. At the end, the Stack must be empty.

7. Pseudocode

FUNCTION validateBrackets(string)

    CREATE empty stack

    FOR EACH character

        IF opening bracket
            PUSH character

        ELSE IF closing bracket

            IF stack is empty
                RETURN false

            POP top opening bracket

            IF opening bracket does not match
                RETURN false

    RETURN whether stack is empty

11. Big-O

Time: O(n)

We look at each character once.

Space: O(n)

In the worst case, every character could be an opening bracket stored in the Stack.

12. Final Takeaway

OPENING BRACKET ↓ PUSH CLOSING BRACKET ↓ Check top of Stack ↓ Correct match? ↙ ↘ NO YES ↓ ↓ false POP END OF STRING ↓ Stack empty? ↙ ↘ YES NO ↓ ↓ true false

Multi-Bracket Validation works well with a Stack because brackets must close in the reverse order they were opened.
