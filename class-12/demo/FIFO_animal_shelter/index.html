🐶 🐱 FIFO Animal Shelter

Learning Queues with Dogs and Cats

🎯 Goal

Today we are learning how to create an Animal Shelter that follows a FIFO system.

FIFO = First In, First Out

The animal that has been waiting the longest should be the first animal of that species adopted.

🧠 Think About a Real Shelter

Imagine these animals arrive in this order:

🐶 Buddy → 🐱 Luna → 🐶 Max → 🐱 Milo

Buddy arrived before Max.

Therefore, if someone wants to adopt a dog, Buddy should leave before Max.

📦 Our Data Structure

We can make the problem easier by keeping two queues.

🐶 Dog Queue

FRONT                         BACK

Buddy → Max → Rocky
  ↑
leaves first

🐱 Cat Queue

FRONT                       BACK

Luna → Milo → Zoe
 ↑
leaves first
Remember:

Animals enter at the back of the queue.

Animals leave from the front of the queue.

➕ enqueue()

enqueue() means:

Add something to the queue.

For example:

shelter.enqueue({
  name: "Buddy",
  species: "dog"
});

Our program checks the animal's species. 

Is Buddy a dog?

YES

↓  

Add Buddy to the dog queue.

➖ dequeue()

dequeue() means:

Remove something from the front of the queue.

For example:

shelter.dequeue("dog");

This means:

Find the DOG queue.

↓

Find the dog at the FRONT.

↓

Remove that dog.

↓

Return that dog.

🔄 Example

Suppose our shelter currently looks like this:

Dogs

Buddy → Max → Rocky

Cats

Luna → Milo

Now we run:

shelter.dequeue("dog");

Buddy leaves because Buddy is at the front.

RETURN:

Buddy

The dog queue becomes:

Max → Rocky

⚠️ Invalid Preference

Our shelter only works with: 

"dog"

or

"cat"

If someone asks for:

shelter.dequeue("bird");

we return:

null

null means that there is no valid animal to return.

🧪 Testing Our Thinking

Action Expected Result
enqueue Buddy the dog Buddy enters dog queue
enqueue Luna the cat Luna enters cat queue
dequeue("dog") Oldest dog is returned
dequeue("cat") Oldest cat is returned
dequeue("bird") null
dequeue from empty queue null

⏱️ Big-O

Big-O describes how much work our program has to do as the amount of data grows.

Operation Big-O Meaning
enqueue() O(1) Add directly to the back
dequeue() O(1) Remove directly from the front
Space O(n) We store all animals
Important JavaScript note:

If you use a normal JavaScript array and shift(), removing the first item is actually O(n).

A real Queue class can be designed so removing from the front is O(1).
