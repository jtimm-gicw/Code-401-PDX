Linked List Insertion in JavaScript

A beginner-friendly demonstration of nodes, links, and the append, insert before, and insert after operations.

What Is a Linked List?

Definition: A linked list is a data structure made of individual objects called nodes. Each node stores a value and a reference to the next node.

Think of a linked list like a chain. Each link in the chain knows where the next link is.

head → 1 → 3 → 2 → X

The head points to the first node. Each node has a next property that points to the next node. X represents null, meaning there is no next node.

What Is a Node?

A node is a simple object containing two important pieces of information:

  • value — the data stored in the node.
  • next — a reference to the next node.
const node = {
  value: 5,
  next: null
};

In our JavaScript file, we create nodes with a Node class so we can easily create as many nodes as we need.

Linked List Insertion

Insertion means adding a new node to an existing linked list.

There are three insertion operations in this demonstration:

Method What it does
append() Adds a node to the end of the list.
insertBefore() Adds a node immediately before the first matching value.
insertAfter() Adds a node immediately after the first matching value.

1. Append

append(value)

append() adds a new node to the end of the linked list.

Example

Before:

head → {1} → {3} → {2} → X

append(5)

After:

head → {1} → {3} → {2} → {5} → X

If the list is empty, the new node becomes the head. 

Before:

head → X

append(1)

After:

head → {1} → X

2. Insert Before

insertBefore(value, newValue)

insertBefore() searches for the first node containing the specified value and places the new node immediately before it. 

Before:

head → {1} → {3} → {2} → X

insertBefore(3, 5)

After:

head → {1} → {5} → {3} → {2} → X

Why is this method a little tricky?

To insert a node before another node, we need to change the next reference of the node that comes before the target. 

Before:

{1} → {3}

After:

{1} → {5} → {3}

If the target is the head, we handle it as a special case because the new node must become the new head.

Important: If the target value is not found, the list does not change.

3. Insert After

insertAfter(value, newValue)

insertAfter() searches for the first node containing the specified value and places the new node immediately after it. 

Before:

head → {1} → {3} → {2} → X

insertAfter(3, 5)

After:

head → {1} → {3} → {5} → {2} → X

How does it work?

First, the new node points to the node that originally came after the target. Then the target node points to the new node. 

Before:

{3} → {2}

Step 1:

{3} → {5} → {2}

Step 2:

The links are now correct.
Important: If the target value is not found, the list does not change.

What Happens with Duplicate Values?

The feature tasks specify that insertion should happen around the first node that contains the target value. 

Starting list:

head → {1} → {2} → {2} → X

insertBefore(2, 5)

Result:

head → {1} → {5} → {2} → {2} → X

Only the first 2 is used as the target. 

Starting list:

head → {1} → {2} → {2} → X

insertAfter(2, 5)

Result:

head → {1} → {2} → {5} → {2} → X

The Most Important Idea

Linked list insertion is primarily about changing references.

A → B

If we insert X between A and B:

A → X → B

We do not need to move every other node. We change which node points to which node.

Student tip: When learning linked lists, draw the nodes and arrows on paper. Think about which next references need to change before writing the JavaScript.
