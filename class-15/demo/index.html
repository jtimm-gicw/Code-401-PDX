1. Start With One Node

A node is one container in a tree. It stores a value and can point to a left child and a right child.

🌱 Root

The top node where the tree begins.

👶 Child

A node connected underneath another node.

🍃 Leaf

A node with no children.

🔗 Edge

The line connecting a parent node to a child.

class Node { constructor(value) { this.value = value; this.left = null; this.right = null; } }

2. What Makes It a Binary Tree?

Binary means each node can have at most two children: one left and one right. A regular Binary Tree does not require smaller values on the left.

3. Depth-First Traversals

Traversal simply means visiting the nodes. The three methods visit the same tree but save the values in a different order.

Pre Order

ROOT → LEFT → RIGHT

Root goes first.

In Order

LEFT → ROOT → RIGHT

Root goes in the middle.

Post Order

LEFT → RIGHT → ROOT

Root goes last.

Choose a traversal to watch the visit order.

Instructor tip: Ask students to predict the next highlighted node before it changes.

4. Binary Search Tree (BST)

A BST adds an organization rule: smaller values go left; larger values go right. That rule helps us decide which direction to travel.

⬅ Smaller

value < current → LEFT

Larger ➡

value >= current → RIGHT

5. How the Classes Fit Together

Node ├── value ├── left └── right BinaryTree ├── root ├── preOrder() ├── inOrder() └── postOrder() BinarySearchTree extends BinaryTree ├── inherits the traversal methods ├── add(value) └── contains(value)

A BinarySearchTree extends BinaryTree, meaning it gets the Binary Tree features and adds BST-specific features.
