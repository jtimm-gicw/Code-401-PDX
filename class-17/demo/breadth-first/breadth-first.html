Breadth-First Traversal (BFS)

Learn how to visit a binary tree one level at a time, left to right. Follow the animation, check the queue, and practice with JavaScript.

Binary TreeQueue = FIFOTime: O(n)

1. First, understand the idea

A binary tree starts with a root. Each node can have a left child, a right child, both, or neither.

Breadth-first traversal visits the top level, then the next level, then the next. On each level, it goes from left to right.

Think of reading rows of seats in a theater: finish a row before moving to the next.

How do we remember the next node?

We use a queue. A queue follows FIFO: First In, First Out. Add children at the back and process nodes at the front.

Remove node → Save its value
Add left child → Add right child
Repeat until queue is empty

Edge case: If the tree has no root, return an empty array []. BFS does not sort the numbers.

4. The algorithm in everyday language

  1. Create an empty result array.
  2. If the tree is empty, return the empty array.
  3. Add the root to the queue.
  4. Take the next node from the front of the queue.
  5. Save its value in the result array.
  6. Put its left child in the queue, if one exists.
  7. Put its right child in the queue, if one exists.
  8. Repeat until the queue is empty; return the result.

Pseudocode

FUNCTION breadthFirst(tree)
  result = []
  IF tree is empty: RETURN result
  queue = [root]
  WHILE queue has waiting nodes
    current = next node in queue
    ADD current.value TO result
    IF current.left exists: ADD left TO queue
    IF current.right exists: ADD right TO queue
  RETURN result

5. JavaScript: build a tree and traverse it

Open breadth-first.js to see the full commented code. The two classes are Node (one node) and BinaryTree (the tree's root).

const tree = new BinaryTree();
tree.root = new Node(10);
tree.root.left = new Node(5);
tree.root.right = new Node(20);

console.log(breadthFirst(tree));
// [10, 5, 20]

Key JavaScript detail: In the file, we use a front index instead of shift() to read the next queue entry. That avoids repeatedly moving array elements.

7. Explain the Big-O

Time: O(n)

Every node is processed once. If the tree has 10 nodes, we process 10 nodes; if it has 100, we process 100. That is linear time.

Space: O(n)

We store an array of results and a queue. In our code, the queue array can grow to hold all n nodes.

Interview answer: “I used a FIFO queue to process one level at a time. I visit each node once, so time is O(n), and the result and queue use O(n) space.”
