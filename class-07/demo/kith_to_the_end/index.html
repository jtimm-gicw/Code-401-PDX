Linked List: Kth From the End

COUNT → CALCULATE → WALK → ANSWER

🎯 Our Goal

We want to find a node by counting from the end of a linked list.
A
HEAD
→
B
 
→
C
 
→
D
 
→
E
TAIL

🔢 What Does k Mean?

k tells us how far the target is from the tail.

k = 0 Last node → E
k = 1 One before last → D
k = 2 Two before last → C
k = 3 Three before last → B
k = 4 Four before last → A
Important: k = 0 means the tail itself. We start counting at zero.

🧠 The Simple Strategy

We can turn the problem into three easy jobs:

1

COUNT

How many nodes are in the linked list?

2

CALCULATE

Use the number of nodes and k to find the target's position from the HEAD.

3

WALK

Start at HEAD and walk to that position.

target index = length - 1 - k

Then return the value at that position.

💻 The Code

Notice how the code follows the same three ideas we just used on the whiteboard.

// 1. COUNT
const length = this.countNodes();

// 2. CALCULATE
const targetIndex = length - 1 - k;

// 3. WALK
let current = this.head;

for (let i = 0; i < targetIndex; i++) {
  current = current.next;
}

// 4. RETURN
return current.value;
Teacher tip: Have students say the four actions out loud:

COUNT → CALCULATE → WALK → RETURN

❓ Why Do We Subtract 1?

This is usually the trickiest part of the formula.

Remember that indexes start at 0.

A
index 0
→
B
index 1
→
C
index 2
→
D
index 3
→
E
index 4

Five nodes means the last index is 4, not 5.

5 nodes → last index is 5 - 1 → index 4

That's why our formula is:

length - 1 - k

⚠️ Edge Cases

1. k Is Too Large

Our list has 5 nodes:

A → B → C → D → E

Valid values are:

k = 0, 1, 2, 3, 4

If we ask for k = 5, there is no valid node.

2. Empty List

What if the linked list has no nodes?

head → null

There is nothing to find, so the method returns null.

📈 Big-O Complexity

Time: O(n)

We walk through the list to count it and then walk to the target.

Space: O(1)

We only use a few variables. We do not create another list.

Interview note: FAST & SLOW can solve this in one pass, but students do not need that technique to understand the basic problem first.
