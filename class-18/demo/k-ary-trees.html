🌳 Understanding K-ary Trees

Learn what a k-ary tree is, how to build one in JavaScript, how to visit its nodes, and how to create a new FizzBuzz tree.

1. Concept2. Build a tree3. DFS4. FizzBuzz5. Practice

1. What is a k-ary tree?

A k-ary tree is a collection of connected nodes. Each node can have up to k children.

Example: If k = 3, each node may have 0, 1, 2, or 3 children. This is called a 3-ary tree.

🔵 Root

The top node where the tree begins. Here, that is 15.

🟢 Children

Nodes directly connected below a parent. The root has children 3, 5, 7.

🟣 Leaf

A node without children. Here: 30, 8, 5, 7.
Remember: A 3-ary tree does not require every node to have exactly three children. Three is only the maximum.

2. How do we build a tree in JavaScript?

Each Node stores a value and a children array. The KaryTree stores the root.

class Node {
  constructor(value) {
    this.value = value;
    this.children = [];
  }
}

class KaryTree {
  constructor(root = null) {
    this.root = root;
  }
}

Connecting parent and child

const root = new Node(15);
const child3 = new Node(3);
const child5 = new Node(5);
const child7 = new Node(7);

root.children.push(child3, child5, child7);
child3.children.push(new Node(30), new Node(8));

const tree = new KaryTree(root);

Notice: We use an array for children because a k-ary node can have more than two children. That is different from a binary tree's left and right properties.

3. How do we visit every node? (DFS)

Depth-first search (DFS) goes down a branch before coming back to visit the next sibling. In this lesson, we visit each parent before its children. This is called preorder DFS.

Press Visit next node to start at the root.

Complete visit order: 15 → 3 → 30 → 8 → 5 → 7

Why DFS here? Recursion makes it easy to process a node, then process every one of its children using the same function.
