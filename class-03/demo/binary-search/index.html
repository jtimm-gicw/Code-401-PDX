🔎 Binary Search

Learn how to search a sorted array by repeatedly cutting the search area in half.

🧠 What Is Binary Search?

Binary search is an algorithm used to find a value inside a sorted array.

Instead of checking every item one at a time, binary search looks at the middle of the array and eliminates half of the possible answers.

8
15
16
23
42

👆 The middle value is 15.

⚙️ How Binary Search Works

1
Start

Set left to the beginning and right to the end.

2
Find Middle

Calculate the middle index between left and right.

3
Compare

Compare the middle value with the search key.

4
Eliminate

Search either the left half or the right half.

📝 The Algorithm

Before writing code, we can describe the solution in plain English:

  1. Start at the beginning of the array.
  2. Start at the end of the array.
  3. Find the middle index.
  4. Compare the middle value to the search key.
  5. If they match, return the middle index.
  6. If the key is larger, search the right half.
  7. If the key is smaller, search the left half.
  8. If nothing is found, return -1. 
left = 0
right = array.length - 1

while left <= right

    middle = middle index

    if array[middle] == key
        return middle

    if key > array[middle]
        search right half

    else
        search left half

return -1

⏱️ Big-O Complexity

O(log n)

Time Complexity

Each search eliminates approximately half of the remaining values.

That's why binary search is much faster than checking every item one at a time.

O(1)

Space Complexity

We only need a few variables: left, right, and middle.

We don't create another array.

🎤 Technical Interview Tip

When explaining binary search in an interview, don't just say:

"I'm using binary search."

Explain why it works: 


"The array is sorted, so I can compare the search key
to the middle value. Based on that comparison, I can
eliminate half of the remaining search space.

I continue doing that until I find the value or there
are no values left to search.

The time complexity is O(log n) and the extra space
complexity is O(1)."
