Reverse an Array

A beginner-friendly JavaScript demonstration of how to reverse an array without using the built-in reverse() method.

What Is the Challenge?

Goal: Write a function called reverseArray that takes an array as an argument and returns the elements in reverse order.

The important restriction is that we cannot use JavaScript's built-in reverse() method. 

array.reverse();

Instead, we need to think about how arrays work and solve the problem ourselves.

Understanding an Array

Arrays store values in numbered positions called indexes.

1
2
3
4
5

Index: 0    1    2    3    4

Notice that the first element is at index 0, not index 1.

Remember: The last index of an array is always:

array.length - 1

What Does "Reverse" Mean?

Reversing an array means that the last element becomes the first element, the second-to-last becomes the second element, and so on.

Original

1
2
3
4
5

Reversed

5
4
3
2
1

Our Algorithm

An algorithm is simply a series of steps we follow to solve a problem.

1 Create an empty array

We need somewhere to store our reversed values. 

const reversedArray = [];

2 Start at the last index

Instead of starting at index 0, start at the last index and move backward. 

array.length - 1

3 Move backward through the array

A for loop can move from the last index toward index 0. 

for (
  let index = array.length - 1;
  index >= 0;
  index--
)

4 Add each value to the new array

As we move backward through the original array, we add each value to our new array. 

reversedArray[reversedArray.length] = array[index];

5 Return the result 

return reversedArray;

Step-by-Step Example

Suppose we have: 

const numbers = [10, 20, 30, 40];

The indexes are: 


Value:    10    20    30    40
Index:     0     1     2     3
                         ↑
                     Last index

First iteration

Start at index 3. 

numbers[3] = 40

New array: 

[40]

Second iteration

Move backward to index 2. 

numbers[2] = 30

New array: 

[40, 30]

Third iteration

numbers[1] = 20

New array: 

[40, 30, 20]

Fourth iteration

numbers[0] = 10

Final result: 

[40, 30, 20, 10]

The Solution

The complete function is intentionally small. It has one responsibility: reverse an array. 

function reverseArray(array) {

  const reversedArray = [];

  for (
    let index = array.length - 1;
    index >= 0;
    index--
  ) {

    reversedArray[reversedArray.length] = array[index];

  }

  return reversedArray;
}

Single-Responsibility Principle

The challenge asks us to use the Single-responsibility principle.

This means a function should have one clear job.

Function Responsibility
reverseArray() Reverse the array.
Testing code Test and display the results.

We don't want one giant function that tries to reverse the array, print the results, validate every possible input, and perform unrelated tasks.

Whiteboard Strategy

Before writing code, ask yourself:

  1. What is my input?
  2. What should my output look like?
  3. Where does the last element live?
  4. How can I move through the array backward?
  5. Where will I store the reversed values?
  6. When should my loop stop?

Key Takeaway

To reverse an array without using reverse():
  1. Create a new empty array.
  2. Start at the last index.
  3. Move backward toward index 0.
  4. Add each value to the new array.
  5. Return the new array.

The key idea is simple: Instead of changing the direction of the original array, read the original array from right to left.
