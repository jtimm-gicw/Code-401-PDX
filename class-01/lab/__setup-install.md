# 📦 Node.js Project — Required Packages

Before starting the lab, install the packages needed for the project.

## Install All Packages

Run this command from your project directory:

```bash
npm install express axios dotenv cors jest supertest
```

## What Each Package Does

| Package | Purpose |
|---|---|
| `express` | Creates our web server |
| `axios` | Makes requests to other APIs |
| `dotenv` | Loads environment variables from `.env` |
| `cors` | Allows requests between different applications |
| `jest` | Runs our automated tests |
| `supertest` | Sends requests to our server during tests |

### After installation, run:

```bash
npm test
```
